\begin{abstract}
We give five theorems and one conditional compatibility observation about classical post-processing of multiple-base order-finding measurements in Shor's algorithm. \textbf{(1) Noise-invariant determinism}: maintaining an accumulated exponent candidate $L$ --- the least common multiple of orders recovered from previous bases --- and augmenting standard continued-fraction post-processing with a divisor search over $L$ yields a procedure (which we call $(C)$) that recovers the order $r_a$ of any new base $a$ deterministically whenever $r_a \mid L$, \emph{independent of the measurement distribution}. \textbf{(2) Logarithmic coverage time (ideal)}: for a semiprime $N = pq$, the expected number of independent uniform bases $K_\lambda$ required for $L = \lambda(N)$ satisfies $\mathbb{E}[K_\lambda] \leq 1 + \sum_{\ell \mid \lambda(N)} 1/(\ell^{s_\ell} - 1)$, where $s_\ell \in \{1, 2\}$ records the $\ell$-Sylow overlap of $(\mathbb{Z}/p)^*$ and $(\mathbb{Z}/q)^*$ (refining a corollary of Pomerance et al.~2017). \textbf{(3) Noise scaling}: under a class of ``destructive'' noise models (depolarizing, bias, modexp), the actual algorithm $K_\lambda$ scales exactly as $\mathbb{E}[K_\lambda^{\text{alg}}(\eta)] = \mathbb{E}[K_\lambda^{\text{ideal}}] / g_M(\eta)$ where $g_M(\eta)$ is the per-base extraction probability. Together: a noise-adjusted logarithmic number of measurements suffice to enter the noise-immune regime of (1). We verify (1) across $17{,}700$ measurements (zero violations), (2) across $17{,}000$ trials (mean within bound), and (3) across 9 noise setups on $N = 437$ (mean error $\sim 11\%$ for the destructive class). Theorem~\ref{thm:regev-c} additionally demonstrates conditional compatibility with Regev's 2023 multi-base framework (\texttt{numpy} simulation, 200 trials $\times$ 4 $N$), provided each measurement coordinate's marginal is Shor-like. Theorem~\ref{thm:hybrid} introduces the \textbf{$(C)$ + Regev $b$-trick hybrid}: applying $(C)$ per coordinate while immediately checking each newly-recovered $\mathrm{ord}(a_i)$ for a nontrivial square root via $b_i^{\mathrm{ord}(a_i)}$. Empirically, the hybrid factors $N = 437$ in $1.03$--$1.70$ runs ($100\%$ success across 5 noise/corruption conditions $\times$ 30 trials), versus $6.7$--$7.1$ ($70\%$) for $(C)$ alone and $3.1$--$4.0$ ($90\%$) for pure $b$-trick. We formalize this with \textbf{Lemma~\ref{lem:b-sqrt}} (per-$b$ nontrivial-sqrt probability $\geq 1/2$ for any semiprime) and a closed-form bound $\mathbb{E}[K] \leq 1/(1 - (1 - g(\eta) \cdot c)^d)$ matching the $N = 437$ empirical mean within $4\%$ (the bound is correspondingly loose at larger $N$, where the per-coordinate recovery rate $g$ drops below $1$; the empirical mean stays in $[1.1, 1.5]$ across $N \in \{1147, 2491, 4087\}$). We discuss the theorem's relation to prior work --- Knill's lcm trick (1995), McAnally's larger-$Q$ convergent enumeration (2001), the Bach--Shallit textbook treatment of $r \mid \lambda(N)$, and the quantum algorithm for computing the Carmichael function (2021) --- and conclude that while every individual ingredient is folklore, the \emph{clean statement of the noise-invariance corollary} appears not to be made explicit in surveyed literature. We additionally show that two natural attempts to improve measurement count beyond this scheme --- adaptive base selection and lattice-based joint post-processing --- yield no further reduction, suggesting the theorem captures the essential structure of the problem at this scale. Finally, we document a universal trial-level mechanism observation at $(N, d) = (437, 4)$: across $13$ independent base sets ($200$ trials $\times$ $12$ $\sigma$ values each), phase noise $\sigma \in [0.005, 0.100]$ reliably flips a small number of trials at one of the $K$-bin boundaries (primarily $K{=}1/K{=}2$, occasionally $K{=}2/K{=}3$) of single-run factoring --- but the direction (success $\leftrightarrow$ failure) is base-set-stochastic, and the cross-seed mean SR ($+0.14\%$, $t{=}0.51$, $p{=}0.31$ at $\sigma{=}0.050$) shows no statistically significant net bias. The mechanism is qualitatively a member of the stochastic-resonance family and provides a conceptual bridge to the noise-as-resource literature (ENAQT) but is too small in absolute terms to enable cryptographic advantage.
\end{abstract}

\section{Background and Notation}
\label{sec:background}

Let $N$ be a composite integer, not a prime power, with $N$ odd. Define $Q = 2^t$ where $t = 2\lceil \log_2 N \rceil$ (so $Q \geq N^2$). For $a \in (\mathbb{Z}/N\mathbb{Z})^*$, let $r_a$ denote the multiplicative order of $a$ modulo $N$ (the smallest positive integer with $a^{r_a} \equiv 1 \bmod N$). Shor's order-finding~\cite{shor1994,nielsenchuang2000} measures $k \in \{0, 1, \ldots, Q-1\}$ from a distribution concentrated near $j \cdot Q / r_a$ for integer $j$. Standard classical post-processing uses the continued-fraction expansion of $k/Q$ to recover $r_a$.

Two classical facts are central:

\begin{description}
\item[(F1) Carmichael bound.] For all $a \in (\mathbb{Z}/N\mathbb{Z})^*$, $r_a \mid \lambda(N)$ where $\lambda$ is the Carmichael function --- the exponent of the group $(\mathbb{Z}/N\mathbb{Z})^*$.
\item[(F2) Order as minimum.] $r_a$ is by definition the smallest positive integer $d$ with $a^d \equiv 1 \bmod N$. Any $d$ satisfying this is a positive multiple of $r_a$.
\end{description}

\section{The $(C)$ Procedure}
\label{sec:procedure}

Let $L \in \mathbb{N}$ be a quantity maintained by the algorithm --- initially $L = 1$, updated as orders are recovered (see Algorithm~\ref{alg:1} below). For a measurement $k \in \{0, \ldots, Q-1\}$ and current $L$, define the candidate pool:
\[
  \mathrm{candidates}(k, L) \;:=\; \mathrm{convergents}(k/Q) \,\cup\, \mathrm{divisors}(L)
\]
where $\mathrm{convergents}(k/Q)$ is the set of denominators of continued-fraction convergents of $k/Q$ up to $N-1$, and $\mathrm{divisors}(L)$ is the set of positive divisors of $L$.

The $(C)$ post-processing is:

\begin{lstlisting}[style=pythonstyle]
def C(a, N, k, Q, L):
    cands = convergents(k/Q, max_denom=N-1) | divisors(L)
    valid = {d in cands : a^d == 1 mod N}
    if valid is empty: return 0
    return minimize_order(a, N, min(valid))
\end{lstlisting}

\noindent
where \texttt{minimize\_order(a, N, d)} reduces $d$ to its smallest positive divisor still satisfying $a^? \equiv 1$ (by removing small prime factors). See Appendix~\ref{app:impl} for the reference implementation.

\begin{lstlisting}[style=pseudostyle, caption={Multi-base accumulation.}, label={alg:1}]
L <- 1
for iteration in 1..max_iter:
    pick a in {2,...,N-1} uniformly at random
    if gcd(a, N) > 1: return factor gcd(a, N)
    if L > 1 and a^L == 1 mod N:
        # fast path: recover r_a classically
        r <- min{d divides L : a^d == 1 mod N}
    else:
        # slow path: quantum measurement followed by (C)
        k <- measure(a, N)
        r <- C(a, N, k, Q, L)
    if r == 0: continue
    L <- lcm(L, r)
    attempt factoring with (a, r) via standard Shor reduction
    or via factor_from_exponent(L) [Miller-Rabin style]
\end{lstlisting}

\section{Main Theorems}
\label{sec:theorem}

This section states two theorems. Theorem~\ref{thm:c-det} characterizes the noise-invariant region of $(C)$. Theorem~\ref{thm:k-lambda} quantifies how fast the algorithm enters that region.

\subsection{Theorem 1: $(C)$-determinism}

\begin{theorem}[$(C)$-determinism]\label{thm:c-det}
If $r_a \mid L$, then $C(a, N, k, Q, L) = r_a$ for every $k \in \{0, \ldots, Q-1\}$.
\end{theorem}

\begin{proof}
Assume $r_a \mid L$. Then $r_a \in \mathrm{divisors}(L) \subseteq \mathrm{candidates}(k, L)$. By construction, $a^{r_a} \equiv 1 \bmod N$, so $r_a \in \mathrm{valid}$. Hence $\mathrm{valid} \neq \emptyset$. By (F2), every $d \in \mathrm{valid}$ is a positive multiple of $r_a$, so $r_a \leq d$. Combining with $r_a \in \mathrm{valid}$ gives $\min(\mathrm{valid}) = r_a$. Finally, $\texttt{minimize\_order}(a, N, r_a) = r_a$ since $r_a$ is already the order.
\end{proof}

\begin{corollary}[Noise invariance]\label{cor:noise}
Theorem~\ref{thm:c-det} makes no assumption on the distribution from which $k$ is drawn. Hence: under any noise model that affects only the measurement step --- including arbitrary distortions of the QFT output distribution --- $(C)$ returns $r_a$ whenever $r_a \mid L$.
\end{corollary}

\begin{corollary}[$L$ integrity]\label{cor:integrity}
When Algorithm~\ref{alg:1} updates $L \leftarrow \mathrm{lcm}(L, r)$, the value $r$ returned by $(C)$ is always either $r_a$ (success) or $0$ (failure). In the success case, $r_a \mid \lambda(N)$ by (F1), so $L$ always remains a divisor of $\lambda(N)$. Under noise, $L$ cannot be corrupted to a value outside the divisors of $\lambda(N)$.
\end{corollary}

\begin{corollary}[Failure region]\label{cor:failure}
$(C)$ can fail only when $r_a \nmid L$. In that case, success depends on $\mathrm{convergents}(k/Q)$ containing some positive multiple of $r_a$ --- the classical ``$(B)$-path.''
\end{corollary}

\subsection{Theorem 2: Number of bases to reach $\lambda(N)$}

Theorem~\ref{thm:c-det} holds \emph{given} $r_a \mid L$. We now bound how many independent bases suffice to reach the global condition $L = \lambda(N)$, after which Theorem~\ref{thm:c-det} applies to every subsequent base.

Let $N = pq$ be a semiprime with $p, q$ distinct odd primes. Let $a_1, \ldots, a_K$ be independent uniform samples from $(\mathbb{Z}/N\mathbb{Z})^*$, with orders $r_1, \ldots, r_K$, and $L_K := \mathrm{lcm}(r_1, \ldots, r_K)$. Let $K_\lambda := \min\{K : L_K = \lambda(N)\}$. For each prime $\ell \mid \lambda(N)$ define
\[
  s_\ell \;:=\; \bigl|\bigl\{\xi \in \{p, q\} : v_\ell(\xi - 1) = v_\ell(\lambda(N))\bigr\}\bigr| \;\in\; \{1, 2\},
\]
where $v_\ell$ denotes the $\ell$-adic valuation.

\begin{theorem}[$K_\lambda$ distribution]\label{thm:k-lambda}
For $K \geq 1$,
\begin{align}
  \mathbb{P}[L_K < \lambda(N)] \;&\leq\; \sum_{\ell \mid \lambda(N)} \ell^{-K \cdot s_\ell} \;\leq\; \omega(\lambda(N)) \cdot 2^{-K} && \text{(tail bound)} \\
  \mathbb{E}[K_\lambda] \;&\leq\; 1 + \sum_{\ell \mid \lambda(N)} \frac{1}{\ell^{s_\ell} - 1} && \text{(expectation)} \\
  \mathbb{P}\bigl[K_\lambda > \lceil \log_2(\omega(\lambda(N))/\varepsilon) \rceil\bigr] \;&\leq\; \varepsilon \quad \text{for any } \varepsilon \in (0, 1) && \text{(high-probability)}
\end{align}
\end{theorem}

\begin{proof}
By CRT, $(\mathbb{Z}/N\mathbb{Z})^* \cong C_{p-1} \times C_{q-1}$, and a uniform $a \in (\mathbb{Z}/N\mathbb{Z})^*$ corresponds to an independent uniform pair $(x, y)$.

\emph{Step 1 (cyclic-group valuation distribution).} In cyclic $C_n$ with $v := v_\ell(n)$, the set $\{x : \mathrm{ord}(x) \mid m\}$ equals the unique subgroup of order $m$, for $m \mid n$. Hence $\{x : v_\ell(\mathrm{ord}(x)) \leq k - 1\}$ is the subgroup of order $\max\{m \mid n : v_\ell(m) \leq k - 1\} = n \cdot \ell^{-(v - k + 1)}$. Therefore for uniform $x \in C_n$:
\[
  \mathbb{P}[v_\ell(\mathrm{ord}(x)) \geq k] \;=\; 1 - \ell^{-(v - k + 1)} \quad (1 \leq k \leq v).
\]

\emph{Step 2 (per-base miss probability).} Let $v_p := v_\ell(p-1)$, $v_q := v_\ell(q-1)$, $v := v_\ell(\lambda(N)) = \max(v_p, v_q)$. Then $v_\ell(\mathrm{ord}(a)) = \max(v_\ell(\mathrm{ord}(x)), v_\ell(\mathrm{ord}(y)))$. By independence of $x, y$ and Step~1:
\[
  \mathbb{P}[v_\ell(\mathrm{ord}(a)) < v] \;=\; \mathbb{P}[v_\ell(\mathrm{ord}(x)) < v] \cdot \mathbb{P}[v_\ell(\mathrm{ord}(y)) < v] \;=\; (1/\ell)^{s_\ell}
\]
(if $v_p < v$, the first factor is $1$; if $v_p = v$, it equals $1/\ell$ by Step~1 with $k = v$. Likewise for $y$. $s_\ell$ counts the contributors.)

\emph{Step 3 (tail bound).} By independence across bases, $\mathbb{P}[\text{$\ell$-component of $L_K$ not covered}] = \ell^{-K s_\ell}$. Union bound over primes $\ell \mid \lambda(N)$ gives the first inequality. Since $\ell \geq 2$ and $s_\ell \geq 1$, each summand is $\leq 2^{-K}$, giving the second.

\emph{Step 4 (expectation).} $\mathbb{E}[K_\lambda] = \sum_{K \geq 0} \mathbb{P}[L_K < \lambda(N)]$. The $K = 0$ term is $1$ (since $L_0 = 1 < \lambda(N)$). For $K \geq 1$, apply the tail bound and interchange sums:
\[
  \mathbb{E}[K_\lambda] \;\leq\; 1 + \sum_\ell \sum_{K \geq 1} \ell^{-K s_\ell} \;=\; 1 + \sum_\ell \frac{1}{\ell^{s_\ell} - 1}.
\]

\emph{Step 5 (high-probability).} Solve $\omega(\lambda(N)) \cdot 2^{-K} \leq \varepsilon$ for $K$.
\end{proof}

\paragraph{Asymptotic.} By the Hardy--Ramanujan theorem, $\omega(p-1) \leq (1 + o(1)) \log \log p$ for almost all primes $p$. Hence for typical semiprimes $\omega(\lambda(N)) = O(\log \log N)$ and $\mathbb{E}[K_\lambda] = O(\log \log \log N)$.

\paragraph{Empirical verification.} We measure the empirical $\mathbb{E}[K_\lambda]$ over 1{,}000 independent trials per $N$, across 17 semiprimes from $N = 15$ to $N = 4087$. In every case, the empirical mean stays within $0.5$ of the bound, and is often within $0.05$--$0.1$. See Appendix~\ref{app:k-lambda} for the full table.

\paragraph{Comparison to Pomerance et al.}
Pomerance et al.~\cite{pomerance2017} prove $e(G) \leq d + 2.752$ for any finite abelian $G$, where $e(G)$ is the expected number of uniform samples needed to \emph{generate} $G$ and $d$ is the maximum Sylow generator count. For $G = (\mathbb{Z}/N\mathbb{Z})^*$ with $N = pq$, $d \leq 2$ so $e(G) \leq 4.752$. Since reaching $\lambda(N)$ via $\mathrm{lcm}$ is weaker than generating, $\mathbb{E}[K_\lambda] \leq e((\mathbb{Z}/N\mathbb{Z})^*) \leq 4.752$ follows as a corollary. Theorem~\ref{thm:k-lambda}(c) refines this in two ways: (i) by using the explicit $\ell$-Sylow structure of $(\mathbb{Z}/N\mathbb{Z})^*$ rather than a generic abelian bound; (ii) by tailoring to ``reach exponent'' rather than ``generate.'' For $N = 4087$, Theorem~\ref{thm:k-lambda}(c) gives $\mathbb{E}[K_\lambda] \leq 2.475$ versus Pomerance et al.'s $\leq 4.752$ and the empirical mean of $2.26$.

\subsection{Theorem 3: Algorithm $K_\lambda$ under destructive noise}

Theorem~\ref{thm:k-lambda} bounds the \emph{ideal} $K_\lambda$ --- assuming the orders $r_{a_i}$ are extracted noise-freely. The full algorithm performs $(C)$ post-processing on noisy measurements, which can fail to recover $r_{a_i}$ and waste the corresponding base.

We isolate a class of noise models for which this overhead admits a clean closed form. A noise model $M$ is \textbf{destructive at rate $\eta$} if each measurement is, independently, replaced with probability $\eta$ by a draw from an $a$-independent distribution $D_M$, and otherwise is noise-free. Examples: depolarizing ($D_M$ uniform), bias-to-zero ($D_M = \delta_{k=0}$). Counter-examples: phase decoherence, amplitude damping (functional transformations of the ideal distribution).

Let $g_0 := \mathbb{P}[(C)\ \text{recovers}\ r_a \mid \text{noise-free}]$ and $g_{\text{unif}}^M := \mathbb{P}[(C)\ \text{recovers}\ r_a \mid k \sim D_M]$. Define $g_M(\eta) := (1-\eta) g_0 + \eta \cdot g_{\text{unif}}^M$.

\begin{theorem}[Algorithm $K_\lambda$ for destructive noise]\label{thm:k-lambda-alg}
Assume $M$ is destructive at rate $\eta$. Then $K_\lambda^{\text{alg}}(\eta)$, the number of bases drawn by Algorithm~\ref{alg:1} before $L = \lambda(N)$, satisfies
\[
  \mathbb{E}[K_\lambda^{\text{alg}}(\eta)] = \mathbb{E}[K_\lambda^{\text{ideal}}] / g_M(\eta),
\]
and in particular $\mathbb{E}[K_\lambda^{\text{alg}}(\eta)] / \mathbb{E}[K_\lambda^{\text{alg}}(0)] = g_0 / g_M(\eta)$.
\end{theorem}

\begin{proof}
Markov chain on states $s \in \mathrm{divisors}(\lambda(N))$. At state $s$, per trial:
\begin{itemize}
  \item With prob $\varepsilon_s := \mathbb{P}[r_a \mid s]$ (covered): fast path returns $r_a$ deterministically (Theorem~\ref{thm:c-det}); state unchanged.
  \item With prob $1 - \varepsilon_s$ ($r_a \nmid s$): slow path measures and applies $(C)$. Under destructive $M$, recovery succeeds with prob $g_M(\eta)$ (state-independent: $D_M$ is $a$-independent, so its convergent enumeration is independent of $s$). On success, state advances to $\mathrm{lcm}(s, r_a)$.
\end{itemize}

The nontrivial transition rate from $s$ is $(1 - \varepsilon_s) \cdot g_M(\eta)$, giving $\mathbb{E}[\text{trials in }s] = 1/[(1-\varepsilon_s) g_M(\eta)]$. By linearity:
\[
  \mathbb{E}[K_\lambda^{\text{alg}}(\eta)]
    = \sum_s \frac{1}{(1-\varepsilon_s) g_M(\eta)}
    = \frac{1}{g_M(\eta)} \cdot \sum_s \frac{1}{1-\varepsilon_s}
    = \frac{\mathbb{E}[K_\lambda^{\text{ideal}}]}{g_M(\eta)}.
\]
\end{proof}

\paragraph{Empirical verification ($N = 437$).} Using $g_M(\eta)$ measured by a separate per-base experiment (\texttt{experiments/g\_eta.py}) and $\mathbb{E}[K_\lambda^{\text{ideal}}] = 1.83$ (measured):

The analogous prediction $\mathbb{E}[K_\lambda^{\text{ideal}}] / g_M(L=1, \eta)$ is a \emph{lower} bound on $\mathbb{E}[K_\lambda^{\text{alg}}]$, underestimating the truth by factor $1.4$--$2.4$ at moderate noise and $> 5$ at extreme noise (\texttt{phase} $\sigma = 2.0$: prediction $28.6$, empirical $69.1$). A closed-form for $g_M(s, \eta)$ under structural noise is left as future work.

\subsection{Theorem 4: Compatibility with Regev's multi-base measurement (conditional)}

Regev's 2023 algorithm~\cite{regev2023} uses $d \approx \sqrt{\log N}$ bases per quantum circuit and recovers factorization via lattice reduction on $\sqrt{n} + 4$ independent measurement vectors. We observe that $(C)$ post-processing applies \emph{coordinate-wise} to Regev's measurements, conditional on a marginal-distribution assumption.

\paragraph{Assumption (Regev marginal --- partial validity).} Each measurement of Regev's circuit produces a vector $(k_1, \ldots, k_d) \in \{0, \ldots, Q-1\}^d$. For the \emph{marginal} of each coordinate $k_i$ to be Shor-like --- i.e., $k_i \approx j_i \cdot Q / r_{a_i}$ so that continued fractions of $k_i / Q$ recover $r_{a_i}$ with positive probability --- is sufficient for the $(C)$ framework to apply coordinate-wise.

\paragraph{Caveat on the assumption.} Public summaries of Regev~(2023)~\cite{regev2023} indicate the measurements jointly satisfy a \emph{linear constraint} of the form $\sum_i b_i k_i \approx 0 \pmod{r}$, where the $b_i$ encode quadratic-character structure. The constraint introduces correlations across coordinates but does not prohibit Shor-like marginals --- it adds a low-dimensional structure that Regev's LLL post-processing exploits for \emph{additional} efficiency beyond coordinate-wise recovery. Whether each $k_i$ is \emph{individually} Shor-like (allowing $(C)$ per coordinate) is a property of the marginal that should be verified directly against Regev's distribution. We have not done so; the empirical numbers below assume independent Shor-like marginals as a working model.

\begin{theorem}[Regev-$(C)$ compatibility, conditional]\label{thm:regev-c}
Under the Regev marginal assumption, applying $(C)$ post-processing independently to each coordinate of each Regev measurement yields:
\begin{itemize}
  \item \textbf{(a) Per-coordinate Theorem~\ref{thm:c-det}.} Whenever $r_{a_i} \mid L_{\text{before}}$ for any (run, coordinate) pair, recovery is deterministic regardless of how the marginal distribution of $k_i$ is distorted by noise.
  \item \textbf{(b) Run-level $K_\lambda$ bound.} Let $K_\lambda^{\text{Regev-}(C)}$ be the number of Regev runs before $L = \lambda(N)$. Then $\mathbb{E}[K_\lambda^{\text{Regev-}(C)}] \leq \mathbb{E}[K_\lambda^{\text{ideal}}] / d$ (under noise-free, ignoring intra-run early termination).
  \item \textbf{(c) Noise invariance.} Corollary~\ref{cor:noise} applies coordinate-wise: any measurement-layer noise on Regev's output preserves the recovery of $r_{a_i}$ whenever the corresponding component is covered.
\end{itemize}
\end{theorem}

\begin{proof}
(a) and (c) are direct applications of Theorem~\ref{thm:c-det} and Corollary~\ref{cor:noise} to each coordinate independently --- valid because $(C)$ acts only on the marginal of $k_i$, by the assumption. (b) follows from Theorem~\ref{thm:k-lambda}(b) applied to $K \cdot d$ independent samples: $\mathbb{P}[L_{K \cdot d} < \lambda(N)] \leq \omega(\lambda(N)) \cdot 2^{-K \cdot d}$, so $\mathbb{E}[K \cdot d] \leq \log_2 \omega(\lambda(N)) + O(1)$, giving $\mathbb{E}[K] \leq (\log_2 \omega(\lambda(N)) + O(1)) / d$.
\end{proof}

\subsection{Theorem 5: Hybrid $(C)$ + Regev $b$-trick (factoring)}

The empirical comparison in Section~\ref{sec:theorem} reveals an unexpected consequence of Regev's setup. In Regev's framework, the bases used by the quantum circuit are $a_i = b_i^2 \bmod N$, where $b_i$ are chosen \emph{first} (random in $(\mathbb{Z}/N\mathbb{Z})^*$) and known to the algorithm. This lets Regev's classical post-processing extract a nontrivial square root of $1$ from a short vector $z \in L = \{z : \prod a_i^{z_i} \equiv 1 \bmod N\}$: with $z$ in hand, $b = \prod b_i^{z_i} \bmod N$ satisfies $b^2 \equiv 1 \bmod N$; if also $b \not\equiv \pm 1$, then $\gcd(b \pm 1, N)$ is a factor.

A purely $(C)$-based extraction misses this: in Regev's setup, $\mathrm{ord}(a_i) = \mathrm{ord}(b_i^2)$ is the \emph{odd part} of $\mathrm{ord}(b_i)$ --- the factor of 2 from $\lambda(N)$ is lost. Pure $(C)$ accumulates $L \leq \lambda(N)/2$, and Miller--Rabin reduction (\texttt{factor\_from\_exponent}) fails on odd $L$. Pure Regev's $b$-trick succeeds but requires recovering each $\mathrm{ord}(a_i)$ independently (no multi-base accumulation gain).

\paragraph{Algorithm~2 (Hybrid $(C)$ + Regev $b$-trick).} For semiprime $N$ with $\lambda(N)$ even and Regev's setup ($a_i = b_i^2 \bmod N$, $b_i$ random), apply $(C)$ post-processing coordinate-wise; on each newly-recovered $r = \mathrm{ord}(a_i)$, compute $b \leftarrow b_i^r \bmod N$ and check whether $b \notin \{1, N-1\}$ and $b^2 \equiv 1 \pmod N$. If so, return $\gcd(b \pm 1, N)$.

The algorithm inherits both: (a) Theorem~\ref{thm:c-det}'s noise-invariance per coordinate, and (b) Regev's $b$-trick's ability to factor without requiring $L = \lambda(N)$.

\paragraph{Formal analysis.} We sharpen the empirical statement with two analytical bounds. Let $v_p := v_2(p - 1)$, $v_q := v_2(q - 1)$ (the 2-adic valuations of $p-1, q-1$; both $\geq 1$ since $p, q$ are odd). Decompose $(\mathbb{Z}/N\mathbb{Z})^* \cong C_{p-1} \times C_{q-1}$ via CRT, and for $b \in (\mathbb{Z}/N\mathbb{Z})^*$ let $\alpha_p := v_2(\mathrm{ord}(b \bmod p))$, $\alpha_q := v_2(\mathrm{ord}(b \bmod q))$.

\begin{lemma}[per-$b_i$ nontrivial sqrt probability]\label{lem:b-sqrt}
For uniform random $b \in (\mathbb{Z}/N\mathbb{Z})^*$,
\[
  \mathbb{P}[b^{\mathrm{ord}(b^2)}\ \text{is a nontrivial sqrt of 1 mod}\ N]
    \;=\; \mathbb{P}[\alpha_p \neq \alpha_q]
    \;=\; 1 - 2^{-(v_p + v_q)} \cdot \frac{4^{\min(v_p, v_q)} + 2}{3}
    \;\geq\; \tfrac{1}{2},
\]
with equality at $v_p = v_q = 1$ and approaching $2/3$ as $\min(v_p, v_q) \to \infty$.
\end{lemma}

\begin{proof}
Let $a = b^2 \bmod N$, so $\mathrm{ord}(a) = \mathrm{ord}(b) / \gcd(2, \mathrm{ord}(b))$. If $\mathrm{ord}(b)$ is odd ($\alpha_p = \alpha_q = 0$), $b^{\mathrm{ord}(a)} = b^{\mathrm{ord}(b)} = 1$ --- trivial.

Otherwise (at least one $\alpha \geq 1$), $\mathrm{ord}(a) = \mathrm{ord}(b)/2$:
\begin{itemize}
  \item If $\alpha_p < \alpha_q$: $\mathrm{ord}(b \bmod p) = 2^{\alpha_p} m_p$ divides $\mathrm{ord}(a) = 2^{\alpha_q - 1} \mathrm{lcm}(m_p, m_q)$, so $b^{\mathrm{ord}(a)} \equiv 1 \bmod p$. In $C_{q-1}$, $b^{\mathrm{ord}(a)}$ has order 2 ($2 \mathrm{ord}(a) = \mathrm{ord}(b)$ is a multiple of $\mathrm{ord}(b \bmod q)$, but $\mathrm{ord}(a)$ alone is not), so $b^{\mathrm{ord}(a)} \equiv -1 \bmod q$. By CRT: $b^{\mathrm{ord}(a)} \equiv (1, -1)$ --- a nontrivial sqrt of 1 mod $N$.
  \item $\alpha_p > \alpha_q$: symmetric, $(-1, 1)$, nontrivial.
  \item $\alpha_p = \alpha_q \geq 1$: both coordinates yield $-1$, so $b^{\mathrm{ord}(a)} \equiv -1 \bmod N$ --- trivial.
\end{itemize}

Hence $\mathbb{P}[\text{nontrivial}] = \mathbb{P}[\alpha_p \neq \alpha_q]$. Standard cyclic-group analysis gives the marginals: in $C_n$ with $n = 2^v \cdot m$ ($m$ odd), elements with $v_2(\mathrm{ord}) \leq j$ form the unique subgroup of order $2^j m$. So $\mathbb{P}[\alpha_p = 0] = 2^{-v_p}$ and $\mathbb{P}[\alpha_p = j] = 2^{j - 1 - v_p}$ for $1 \leq j \leq v_p$. $\alpha_p, \alpha_q$ independent (CRT). Summing $\mathbb{P}[\alpha_p = \alpha_q]$ and using $\sum_{j=1}^{m} 4^j = \tfrac{4(4^m - 1)}{3}$ gives the closed form.
\end{proof}

\begin{theorem}[Hybrid factoring --- quantitative bound]\label{thm:hybrid-formal}
Pick $b_1, \ldots, b_d$ uniform random in $(\mathbb{Z}/N\mathbb{Z})^*$ and set $a_i = b_i^2 \bmod N$. Let $g(\eta)$ denote the per-coordinate $(C)$ recovery probability at $L = 1$ under noise $\eta$ (the $g_M(\eta)$ of Section~\ref{sec:theorem}). Let $c := \mathbb{P}[\text{nontrivial sqrt}]$ from Lemma~\ref{lem:b-sqrt} ($c \geq 1/2$). Then:
\begin{itemize}
  \item \textbf{(a) Single-run success.} $\mathbb{P}[\text{1-run success}] \geq 1 - (1 - g(\eta) \cdot c)^d.$
  \item \textbf{(b) $K$-run success with fixed bases.} Letting $X_i$ be the indicator that $b_i^{\mathrm{ord}(a_i)}$ is a nontrivial sqrt of 1, $\mathbb{P}[K\text{-run success}] \geq 1 - ((1 - c) + c(1 - g(\eta))^K)^d$. As $K \to \infty$ this approaches $1 - (1 - c)^d \leq 1 - 2^{-d}$, \emph{bounded by base randomness}.
  \item \textbf{(c) Restart-augmented.} Drawing fresh $b_i$ after $K_{\max}$ failed runs amplifies success. For $K_{\max} = O(\log(1/\varepsilon)/g)$ and $d \geq \log_2(1/\varepsilon)$, $\mathbb{E}[\text{total runs}] = O(K_{\max})$ for failure probability $\varepsilon$.
  \item \textbf{(d) Asymptotic.} For $d \geq \lceil \log_2 (1/\varepsilon) \rceil$ and $g(\eta) = \Omega(1)$, $\mathbb{E}[\text{total runs}] = O(1)$ as $N \to \infty$.
\end{itemize}
At $N = 437$, $d = 4$, with empirical $g \approx 1$: the 1-run bound gives $\mathbb{P}[\text{success}] \geq 15/16 \approx 0.94$, so $\mathbb{E}[K] \leq 16/15 \approx 1.07$. Empirical mean: $1.03$ and success $30/30$ in our original Section~\ref{sec:theorem} table; in a second independent run with the same parameters but $\mathtt{max\_runs} = 10$ we observed $27/30$ success --- matching the $\sim 1/16$ expected fraction of ``all bases bad'' trials.
\end{theorem}

\subsection{Trial-level noise sensitivity at K-bin boundaries (universal mechanism observation)}

We document a mechanistically clean phenomenon in the hybrid $(C) + $ Regev $b$-trick algorithm at $(N, d) = (437, 4)$: under phase noise of magnitude $\sigma \in [0.005, 0.100]$, every sampled base set exhibits a small set of trials moving across one of the $K$-bin boundaries of single-run factoring --- most often the $K = 1 / K = 2$ boundary, occasionally the $K = 2 / K = 3$ boundary. Across $13$ independent seeds $\times$ $200$ trials $\times$ $12$ $\sigma$ values ($31{,}200$ trial-measurements), the \emph{boundary-flip mechanism is universal} ($13/13$ seeds), but the \emph{direction} (success $\leftrightarrow$ failure) is base-set-dependent and shows no statistically significant net bias: mean SR $= +0.144\%$, sd $1.016\%$, SE $0.282\%$, $t = 0.51$, $p (\text{1-sided}) = 0.31$ at $\sigma = 0.050$.

The mechanism is qualitatively a member of the stochastic resonance family (Benzi et al.\ 1981; Wellens--Buchleitner 2004 for the quantum variant) and the $\sigma$-curve quantitatively matches the classical Benzi shape (saturation plateau followed by overload decline). It provides a clean conceptual bridge between integer factoring and the broader noise-as-resource literature (ENAQT, Plenio--Huelga 2008) but is too small in absolute terms ($1$--$7$ trial flips per $200$ = $\pm 0.3$--$2\%$ per seed) to have cryptographic implications.

\paragraph{$\sigma$-curve direction asymmetry.}

\end{itemize}

\paragraph{Speculative mechanism.}
Small phase noise broadens the QFT measurement peak around $j \cdot Q / r$ slightly. For each trial the broadening either exposes an alternative convergent candidate that succeeds ($K$ decrease) or perturbs a previously-found one into failure ($K$ increase); the outcome per base set is determined by which side of the active boundary holds more \emph{near-miss} trials in the noise-free measurement. The plateau structure follows from the discreteness of the affected trial set: once $\sigma$ exceeds the per-trial peak width that borderline trials require to flip, additional $\sigma$ has no marginal effect within the plateau. The overload decline at large $\sigma$ reflects the same dynamic in reverse --- flipped trials become unstable and revert.

\paragraph{Why this effect is small compared to existing noise-as-resource literature.}
Existing examples in the broader noise-as-resource paradigm --- environment-assisted quantum transport in the FMO complex (Plenio--Huelga 2008, with efficiency boost from $\sim 13\%$ to $\sim 47\%$), classical stochastic resonance in neural detection (Benzi et al.\ 1981; with detection-rate improvement from $\sim 0\%$ to $\sim 50\%$), and bistable-potential SR (signal amplification $30\%+$) --- all share a common structural feature: the \emph{noise-free} baseline is \emph{sub-functional} (stuck in a local minimum, trapped by destructive interference, or sub-threshold), and noise \emph{restores function} by breaking the trap. Effect magnitudes are large because the system goes from non-functional to functional. Our system has no such structural feature: the noise-free hybrid algorithm already factors in $\sim K_{\text{baseline}}$ runs (mean $K = 1.92$ at $(N, d) = (437, 4)$, meaning $\sim 95\%$ of trials succeed in $1$--$2$ runs), and there is no destructive interference, bistability, or threshold trapping the noise-free baseline. Phase noise can therefore only flip a small number of \emph{borderline} trials at $K$-bin boundaries ($1$--$7$ per $200$ = $\pm 0.3$--$2\%$ per seed), not switch the algorithm from ``broken'' to ``working.'' The mechanism we identify is the \emph{same} as in classical SR (saturation plateau + overload decline), but the system is in the regime of ``marginal improvement on a working system'' rather than ``function-restoration on a stuck system.'' A large noise-as-resource effect in quantum factoring would require deliberately engineering a sub-functional baseline (e.g., adding artificial rejection thresholds or constructing destructive-interference structures); such engineered amplification is left to future work.

The ceiling cells show near-zero SR (no $K \geq 2$ population to flip); the noise-floor cell shows variance dominating effect; the active-boundary cells show small magnitudes regressing under multi-seed measurement. Single-seed grid measurements at the remaining cells (mostly positive, one $-4.89\%$ at $(2491, 2)$) are consistent with this picture: per-seed variance $\approx$ effect magnitude, mean direction not yet determined.

\paragraph{What we earlier over-claimed and have since retracted.}
\begin{enumerate}
  \item \emph{$+17.86\%$ peak at $(1147, 2, 0.01)$} ($150$ trials $\times 1$ seed): re-measured at $1000$ trials $\times 4$ seeds gave mean $+0.42\%$ ($t = 0.50$, not significant) --- single-seed direction fluctuation within mechanism variance.
  \item \emph{Polynomial scaling $\text{SR} \propto N^\alpha$}: rejected when $N = 2491$ cells showed near-zero or negative SR. The mechanism predicts no $N$-scaling.
  \item \emph{$\sigma_{\text{opt}} \propto N^\alpha$ (``small lock, small wiggle'')}: rejected by $\sigma$-scan finding $\sigma_{\text{opt}} \approx 0.010$ independent of $N$ --- consistent with the discrete saturation plateau.
  \item \emph{``Anti-Optimization Principle'' --- $d = 1$ universal positive SR}: undermined by multi-seed re-measurement at $(1147, 1)$ giving $-0.53\% \pm 4.28\%$, consistent with the noise-floor regime.
  \item \emph{V3 sign test $p = 0.03$ as significance}: invalid because $\sigma$ values within the saturation plateau are perfectly correlated. The proper significance test is between-seed direction, which our $13$-seed measurement finds not significant ($p = 0.31$).
  \item \emph{``Goldilocks $K_{\text{baseline}} \approx 2$ regime as a robust SR cell''}: refined. $K_{\text{baseline}} \approx 2$ marks the regime where boundary-flip activity is detectable, but the \emph{direction} is base-set-stochastic, not systematically positive. The boundary flip mechanism is the robust observation; the SR-as-positive-effect interpretation was a single-seed artifact.
\end{enumerate}

\paragraph{Caveats.}
\begin{itemize}
  \item \emph{Effect magnitude is tiny.} $1$--$7$ trial flips per $200$, $\pm 0.3$--$2\%$ $K$ change per seed, no cryptographic implication.
  \item \emph{No net SR direction.} Mean SR across $13$ seeds ($+0.144\%$, $p = 0.31$) is not statistically distinguishable from zero.
  \item \emph{Direction asymmetry of $\sigma$-curve} reflects $K$-distribution skew, not a feature of phase noise itself.
  \item \emph{Phase-noise specific.} Depolarizing and amplitude damping show monotone degradation, not boundary flips.
  \item \emph{Mechanism not formalized at base-set level.} We predict that some $K$-boundary is active and the $\sigma$-curve shape, but not the specific boundary location or flip direction.
\end{itemize}

\paragraph{Open questions.}
\begin{enumerate}
  \item \emph{Direction bias at larger samples.} $30+$ seeds may reveal a small systematic bias hidden in our $13$-seed noise.
  \item \emph{Active-boundary determinants.} Which $K$-boundary becomes active at a given seed is not predictable from $K_{\text{baseline}}$ alone.
  \item \emph{Universality across $N$.} Verification candidates: $(1147, 2), (1147, 3), (4087, 4)$, each at $\sim 2000$-trial multi-seed scale.
  \item \emph{Long-jump events} may reflect cascades or true noise-induced trajectory divergence.
\end{enumerate}

We document this as a universal trial-level mechanism observation with stochastic per-seed direction: the multi-base hybrid Shor algorithm has $K$-bin boundaries that are sensitive to small phase noise, the mechanism is robust across all sampled base sets, but the cross-seed direction is not systematically biased toward improvement. The qualitative connection to the noise-as-resource paradigm is clear; the quantitative net effect is null at our sample size.

\subsection{Joint interpretation}

Theorem~\ref{thm:c-det} says: \emph{once} $r_a \mid L$, success is deterministic regardless of noise. Theorem~\ref{thm:k-lambda} says: an ideal algorithm reaches this state in $O(\log \log \log N)$ bases in expectation. Theorem~\ref{thm:k-lambda-alg} says: under destructive noise, the actual algorithm reaches it in $\mathbb{E}[K_\lambda^{\text{ideal}}] / g_M(\eta)$ bases --- exactly $1/g_M(\eta)$ overhead. Theorem~\ref{thm:regev-c} says: under a marginal-distribution assumption, $(C)$ applies coordinate-wise to Regev's multi-base measurements with corresponding reduction in run count. Theorem~5 closes the loop: combining $(C)$'s $\lambda(N)$ recovery with Regev's $b$-trick yields a complete factoring algorithm that empirically requires $\sim 5\times$ fewer runs than standalone Regev at $N \in \{437, 1147, 2491, 4087\}$. Together they explain the algorithm's empirical robustness: a noise-adjusted logarithmic number of measurements suffice to enter a regime immune to further measurement noise, and the framework composes naturally with Regev's circuit (modulo marginal assumption).

The \S\,3.6 trial-level boundary-flip observation sits \emph{orthogonal} to this main framework: across $13$ base sets at $(N, d) = (437, 4)$, phase noise universally activates a $K$-bin boundary ($K{=}1/K{=}2$ in $77\%$ of seeds, $K{=}2/K{=}3$ in $15\%$, long-jump in $8\%$), but with stochastic per-seed direction and no statistically significant cross-seed net SR (mean $+0.14\%$, $p{=}0.31$). The mechanism is universal at the boundary-flip level; the integrated SR effect is null at our sample size. The effect does not interact with Theorems~1--5 in the regime where they are tight.

\section{Empirical Verification}
\label{sec:empirical}

We verify Theorem~\ref{thm:c-det} across diverse noise models. For each measurement, we log $(r_a, L_{\mathrm{before}}, \mathrm{condition}, \mathrm{success})$ where $\mathrm{condition} := (r_a \mid L_{\mathrm{before}})$ and $\mathrm{success} := ((C) \text{ output} = r_a)$. We count:
\begin{itemize}
  \item \texttt{violations} := count of $\mathrm{condition} = \text{True} \land \mathrm{success} = \text{False}$ (theorem predicts $0$)
  \item \texttt{lucky} := $\mathrm{condition} = \text{False} \land \mathrm{success} = \text{True}$ (recovery via convergents alone)
  \item \texttt{covered} := $\mathrm{condition} = \text{True}$
\end{itemize}

\section{Related Work}
\label{sec:related}

We outline how Theorem~\ref{thm:c-det} relates to existing literature, including which ingredients are folklore and where the gap (if any) lies.

\paragraph{Knill (1995)~\cite{knill1995}.}
Proposes running the quantum step twice for the same base and taking the lcm of denominators recovered from convergents. This is \emph{single-base} lcm. Our $(C)$ extends this to multi-base lcm and augments the candidate pool with $\mathrm{divisors}(L)$.

\paragraph{McAnally (2001)~\cite{mcanally2001}.}
Same-base accumulation: enlarges the Fourier transform modulus to $Q \approx 2 w n^3$ and enumerates \emph{all} convergent denominators in a single measurement, achieving near-certainty per run. Same-base structure, different mechanism ($Q$ enlargement vs.\ $L$ accumulation across bases).

\paragraph{Bourdon--Williams (2007)~\cite{bourdonwilliams2007}.}
Sharp asymptotic lower bound on per-measurement success probability ($\sim 94\%$) via Carmichael-based analysis. Theoretical bound; no algorithmic change.

\paragraph{Ekerå (2021)~\cite{ekera2021}.}
Shows the order of a \emph{single} base typically suffices for complete factorization via smoothness extension. Different direction from our multi-base accumulation; complementary.

\paragraph{Quantum Carmichael (2021)~\cite{carmichaelquantum2021}.}
Algorithm~1 of this paper essentially runs the multi-base lcm to recover $\lambda(N)$. Closest prior work to our framework. The paper \emph{does not augment subsequent measurements' post-processing with $\mathrm{divisors}(L)$}; each order is computed independently.

\paragraph{Ekerå (2024)~\cite{ekera2024}.}
Comprehensive survey of post-processing techniques: continued fractions, lattice post-processing, offset search, divisor search of recovered $r/d$, Seifert's joint solving. \emph{Multi-base accumulation across different $a$ values is not surveyed as a post-processing technique here.}

\paragraph{Bach--Shallit (1996)~\cite{bachshallit1996}.}
Foundational textbook coverage of $r \mid \lambda(N)$, multi-element lcm convergence to $\lambda(N)$, and factoring from a known exponent (Miller--Rabin reduction). Related classical analysis of the Carmichael function distribution: Erd\H{o}s--Pomerance--Schmutz~\cite{erdosps1991}.

\paragraph{Pomerance et al.\ (2017)~\cite{pomerance2017}.}
Shows $e(G) \leq d + 2.752\ldots$ where $d$ is the maximum Sylow generator count. For semiprime $(\mathbb{Z}/N\mathbb{Z})^*$, this gives constant-bounded expected number of bases to \emph{generate} the group (hence reach $\lambda(N)$ via lcm).

\subsection{Three approaches to noise-tolerant Regev factoring}

The Regev 2023 algorithm~\cite{regev2023} (JACM 2025) factors $n$-bit integers via $\sim \sqrt{n}$ runs of a multi-base circuit followed by lattice post-processing. Regev's own analysis requires all runs to be uncorrupted. Three independent approaches to handling corrupted runs have appeared:

\paragraph{Ragavan--Vaikuntanathan (2023/2025)~\cite{ragavan2023}.}
Extends Regev's lattice post-processing with a \emph{filter-then-LLL} stage: corrupted samples are detected via short-vector search on a constructed lattice and discarded; standard Regev LLL post-processing then runs on the uncorrupted survivors. Requires a ``well-spread'' noise distribution assumption. Operates entirely within Regev's lattice framework.

\paragraph{Ekerå--Gärtner (2024)~\cite{ekeragartner2024} --- concurrent with the above.}
Shows that under a different (stronger) assumption on the corruption distribution, \emph{standard} Regev post-processing already tolerates a constant fraction of corrupted samples without filtering. Lattice framework preserved; analysis-only contribution.

\paragraph{This work (Theorem~\ref{thm:regev-c}, conditional).}
Replaces Regev's lattice post-processing with $(C)$ \emph{coordinate-wise} --- each measurement coordinate $k_i$ is processed independently via standard Shor-style continued-fraction recovery plus the divisor search of the accumulated exponent $L$. Output is $\lambda(N)$, from which factorization follows by standard methods (Miller--Rabin reduction on a known exponent). Requires the \emph{marginal Shor-likeness} of each $k_i$ (verified empirically against a joint-constrained model in Section~\ref{sec:theorem}). Noise-tolerance inherits Theorem~\ref{thm:c-det}'s noise invariance per coordinate without needing a filter or distribution assumption.

The three approaches are \emph{orthogonal}: RV~\cite{ragavan2023} adds a filter on top of LLL; EG24~\cite{ekeragartner2024} modifies the assumption while keeping the algorithm; our work replaces the post-processing entirely. Direct head-to-head empirical comparison (RV's Algorithm~6.1 vs.\ $(C)$ coordinate-wise on Regev measurements, under matched noise) is a natural next step but is not performed here.

\paragraph{Position of our contribution.}
Every individual ingredient --- $r \mid \lambda(N)$, multi-base lcm, divisor search given exponent, continued fractions, factoring from exponent --- is folklore or established in the references above. The \emph{clean separation theorem} (noise invariance via the classical verification gate, formalized as Theorem~\ref{thm:c-det}) and its corollaries appear to not be stated explicitly; nor does the \emph{application of multi-base lcm post-processing to Regev's coordinate-wise measurements} (Theorem~\ref{thm:regev-c}) appear in the noise-tolerant-Regev literature surveyed above. We propose Theorems~\ref{thm:c-det}--\ref{thm:regev-c} as: (i) the folklore packaging that gives a uniform explanation for the empirical robustness of multi-base post-processing (Theorems~\ref{thm:c-det}--\ref{thm:k-lambda-alg}), and (ii) an alternative post-processing approach for Regev's framework, distinct from the lattice-based methods of RV and EG24 (Theorem~\ref{thm:regev-c}).

\section{Limitations and Discussion}
\label{sec:limitations}

\paragraph{No measurement saving from adaptive base selection.}
A natural attempt --- pre-filter bases by $a^L \not\equiv 1 \bmod N$ so that every measured base extends $L$ --- yields no improvement in measurement count over the random-selection $+$ fast-path scheme (\texttt{shor\_quantum\_adaptive} vs.\ \texttt{shor\_quantum\_multi} in the companion code). The fast path already skips classical-only bases; pre-filtering shifts the work but does not eliminate any measurement.

\paragraph{Marginal value of lattice post-processing.}
The Knill--Mosca lattice approach strengthens single-base, multi-measurement convergent recovery. In our multi-base framework, $\mathrm{lcm}(r_{a_1}, \ldots, r_{a_k})$ already accomplishes equivalent recovery across bases. We did not find a regime where additional lattice basis reduction (LLL or simpler) provides measurable benefit over the lcm strategy.

\paragraph{The theorem is conditional on $r_a \mid L$.}
When $L = 1$ (start of algorithm), the condition fails and $(C) \equiv (B)$. Theorem~\ref{thm:k-lambda} precisely characterizes this transient: $\mathbb{E}[K_\lambda] \leq 1 + \sum_\ell 1/(\ell^{s_\ell} - 1)$, which is $O(\log \log \log N)$ for typical semiprimes. Empirically, $K_\lambda \leq 14$ across all $17{,}000$ trials at $N \leq 4087$ (Appendix~\ref{app:k-lambda}).

\paragraph{Scope of the framework --- group-exponent learning.}
The multi-base accumulation underlying Theorems~\ref{thm:c-det}--\ref{thm:k-lambda-alg} is specific to \emph{group-exponent learning}: Shor's order finding is fundamentally an algorithm that learns $\lambda(N)$ (the exponent of $(\mathbb{Z}/N\mathbb{Z})^*$) via $\mathrm{lcm}$ of orders, with factorization following as a byproduct. The structure does \emph{not} naturally extend to:
\begin{itemize}
  \item \textbf{Discrete logarithm} (single-instance: a specific $x$ for a specific $(g, h)$; no natural multi-base $\mathrm{lcm}$).
  \item \textbf{Abelian hidden subgroup problem} (single-instance: a specific $H$ for a specific $f$; sublattice accumulation is well-studied but does not gain noise-invariance from a $(C)$-style divisor verifier).
\end{itemize}
It does extend, with no algorithmic change, to \emph{multi-prime} factoring ($N = p_1 \cdots p_k$ with $k \geq 2$): Theorems~\ref{thm:c-det}--\ref{thm:k-lambda-alg} hold verbatim, with $\lambda(N) = \mathrm{lcm}(p_1 - 1, \ldots, p_k - 1)$ and $s_\ell \in \{1, \ldots, k\}$. A useful \emph{composition} is $(C)$+Pohlig--Hellman: use $(C)$ to learn $\lambda(N)$ and hence $\mathrm{ord}(g)$ for any $g$, then apply Pohlig--Hellman for discrete log on $g$. This is a hybrid algorithm, not an extension of the $(C)$ framework itself.

\paragraph{Classical verification gate is assumed exact.}
Theorem~\ref{thm:c-det} relies on $\texttt{pow}(a, d, N)$ returning the correct value. On real hardware, this could in principle be corrupted by classical computation errors, but at standard machine precision this is negligible compared to quantum noise.

\paragraph{Scale of verification.}
Our experiments span $N \in \{77, 143, 209\}$ with 500 trials per noise setup (Sec.~\ref{sec:empirical}) and $N \in \{1147, 2491, 4087\}$ with 100 trials per setup (Appendix~\ref{app:large}), totaling $17{,}700$ measurements. The largest $N = 4087 = 61 \cdot 67$ requires a 24-qubit counting register ($Q = 2^{24} \approx 16.8\text{M}$ amplitudes, $256$ MB at \texttt{complex128}) --- at the upper end of single-machine state-vector simulation. Scaling to cryptographic $N$ requires no algorithmic change; the remaining bottleneck is pure classical simulation memory. Hardware verification on existing NISQ devices is a natural next step.

\section{Conclusion}
\label{sec:conclusion}

We formalize a folklore observation about classical post-processing of multi-base Shor order-finding measurements: augmenting continued-fraction recovery with a divisor search over the accumulated lcm $L$ makes the procedure deterministic whenever the order of the current base divides $L$ --- independent of the measurement distribution, hence robust to all measurement-layer noise models. We complement Theorem~\ref{thm:c-det} with two quantitative bounds: Theorem~\ref{thm:k-lambda} on the number of bases $K_\lambda$ needed to reach the noise-invariant regime (refining a corollary of Pomerance et al.~2017), and Theorem~\ref{thm:k-lambda-alg} characterizing the exact noise overhead $1/g_M(\eta)$ for destructive noise models. We verify Theorem~\ref{thm:c-det} across $17{,}700$ trials at six composite sizes (zero violations), Theorem~\ref{thm:k-lambda} across 17 semiprimes $\times$ 1{,}000 trials, and Theorem~\ref{thm:k-lambda-alg} across 9 noise setups on $N = 437$. Theorem~\ref{thm:regev-c} extends the framework coordinate-wise to Regev's multi-base measurements (conditional on a verified marginal-distribution assumption); Theorem~5 packages this into a hybrid factoring algorithm that empirically requires $\sim 5\times$ fewer runs than standalone Regev at $N \in \{437, 1147, 2491, 4087\}$. Two natural attempts to further reduce measurement count (adaptive base selection, lattice post-processing) yield no improvement, indicating Theorem~\ref{thm:c-det} captures the essential structure at this scale.

Additionally (\S\,3.6), at $(N, d) = (437, 4)$ we measured $K$ with $13$ independent base sets $\times$ $200$ trials $\times$ $12$ $\sigma$ values ($31{,}200$ trial-measurements total) and identified a universal trial-level mechanism: phase noise $\sigma \in [0.005, 0.100]$ flips a small number of trials at one of the $K$-bin boundaries ($K{=}1/K{=}2$ in $77\%$ of seeds, $K{=}2/K{=}3$ in $15\%$) of single-run factoring. The mechanism is robust ($13/13$ seeds), and the $\sigma$-curve follows the classical Benzi--Buchleitner shape (saturation plateau + overload decline). The direction (success $\leftrightarrow$ failure) is determined by base-set-specific $K$-distribution near the active boundary and shows no statistically significant net bias across seeds (mean SR $= +0.144\%$, $t = 0.51$, $p = 0.31$). The observation provides a clean conceptual bridge between integer factoring and the broader \emph{noise-as-resource} literature (ENAQT; Plenio--Huelga 2008) but is too small in absolute terms to enable cryptographic advantage.

The work is best viewed as expository and a foundation for explorations of more substantive improvements: noise-resilient implementations on hardware, the \texttt{lucky} region under structured measurement distributions, the empirical comparison of $(C)$ coordinate-wise vs RV's filter-then-LLL on matched corrupted Regev data, and a deeper theoretical account of when noise transitions from barrier to weak resource in quantum factoring~\cite{regev2023}.

\section{Reference Implementation}
\label{app:impl}

\begin{lstlisting}[style=pythonstyle]
def divisors(n):
    """Divisors of n, ascending."""
    small, large = [], []
    i = 1
    while i*i <= n:
        if n % i == 0:
            small.append(i)
            if i != n // i:
                large.append(n // i)
        i += 1
    return small + large[::-1]


def convergent_denominators(k, Q, max_denom):
    """All convergent denominators of k/Q up to max_denom."""
    a, b = k, Q
    h_prev, h_curr = 0, 1
    k_prev, k_curr = 1, 0
    denoms = []
    while b != 0:
        q = a // b
        a, b = b, a - q*b
        h_prev, h_curr = h_curr, q*h_curr + h_prev
        k_prev, k_curr = k_curr, q*k_curr + k_prev
        if 0 < k_curr <= max_denom:
            denoms.append(k_curr)
        elif k_curr > max_denom:
            break
    return denoms


def minimize_order(a, N, candidate):
    if candidate <= 0 or pow(a, candidate, N) != 1:
        return 0
    r = candidate
    for p in prime_factors(r):
        while r % p == 0 and pow(a, r // p, N) == 1:
            r //= p
    return r


def C(a, N, k, Q, L):
    """The (C) post-processing procedure."""
    cands = set(convergent_denominators(k, Q, N - 1))
    if L > 1:
        cands.update(divisors(L))
    valid = [d for d in cands if d > 0 and pow(a, d, N) == 1]
    if not valid:
        return 0
    return minimize_order(a, N, min(valid))
\end{lstlisting}

\section{Hardware-Calibrated Noise Simulation}
\label{app:hardware}

We additionally simulate $(C)$ at noise levels calibrated to published IBM Quantum Eagle 127-qubit processor specifications (median values, 2024--2025):
\begin{itemize}
  \item $T_1 \approx 150\,\mu\text{s}$ (relaxation), $T_2 \approx 100\,\mu\text{s}$ (dephasing)
  \item 1-qubit gate error $\approx 0.03\%$, 2-qubit (ECR) gate error $\approx 1\%$
  \item Readout error $\approx 2\%$ per bit
\end{itemize}

For an $N = 15$ Shor circuit (12 qubits, $\sim 50\,\mu\text{s}$ depth, $\sim 30$ gates with $\sim 10$ two-qubit), these map to combined noise parameters: \texttt{readout\_flip} $= 0.02$, \texttt{modexp\_error} $= 0.05$, \texttt{amplitude\_damp} $= 0.002$, \texttt{phase\_sigma} $= 0.3$, \texttt{depolarizing} $= 0.01$ (all applied simultaneously).
