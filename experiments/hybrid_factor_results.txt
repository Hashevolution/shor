# 핵심 발견:
# 1. **(C) lcm only 가 Regev setup (a_i = b_i²) 에서 30% 실패**:
#    이유: ord(a_i) 가 λ(N) 의 odd part 만 학습. L 누적이 짝수 안 되어
#    factor_from_exponent 의 Miller-Rabin 환원 실패.
#
# 2. **Regev b-trick 가 90% 성공, ~3 runs 평균**:
#    각 a_i 의 ord 회수시 b_i^ord 의 nontrivial sqrt(1) 확인. 50% 확률로
#    nontrivial → factor. 여러 base 누적시 90% 도달.
#
# 3. **(C)+b-trick hybrid 가 100% 성공, ~1 run 평균** ← 최강:
#    - (C) 의 noise-tolerant per-coordinate recovery 가 ord(a_i) 회수
#    - b-trick 이 매 ord 회수시 즉시 factor 시도
#    - (C) 의 다중 base 누적 (multi-base lcm) + b-trick 의 각 base 인수 시도가
#      직교 결합 → 1-2 runs 면 충분
#
# 4. **노이즈 robustness (Theorem 1 corollary)**:
#    corruption 30% 또는 phase σ=1.0 노이즈에서도 hybrid 1.27-1.70 runs.
#    (C) 의 per-coordinate verification a^d ≡ 1 mod N 이 noise 영향 제거.
