# oracle_tcount_magic — 상태 magic(M₂) ↔ 오라클 비클리포드(T) 비용 (비선형 ANF 단항식 수)
# 명제: M₂(|ψ_f⟩)>0 ⟺ f 비선형 ⟺ U_f 가 T 게이트 요구.  T_proxy = 차수≥2 ANF 단항식 수.

## 0. 도구 검증 — 선형/아핀 f 는 비선형 ANF 단항식 0 (⟹ 클리포드 오라클)
   랜덤 아핀 f (n=3): 비선형 단항식 = 0,  M₂ = 0.0000
   랜덤 아핀 f (n=4): 비선형 단항식 = 0,  M₂ = 0.0000
   랜덤 아핀 f (n=5): 비선형 단항식 = 0,  M₂ = 0.0000
   → 아핀 f 는 T_proxy=0 이고 M₂=0 (둘 다 0).  도구 정상: True

## 1. 비선형 항 추가 → T_proxy 와 M₂ 가 함께 0에서 켜지고 함께 증가 (n=4, s=3)
     추가 AND항  T_proxy        M2
           0        0    0.0000
           1        1    1.5406
           2        2    2.4764
           3        3    3.6962
           4        4    4.4301
   → T_proxy=0 ⟺ M₂=0; 비선형성↑ 이면 둘 다 ↑ (상태 magic ↔ 오라클 T 비용 동반).

## 2. 끝점 — Simon(선형: T_proxy 0, M₂ 0)  vs  Shor modexp(비선형: T_proxy↑, M₂↑)
   알고리즘                in  out  T_proxy        M2
   Simon (선형오라클)        3    3        0    0.0000
   Simon (선형오라클)        4    4        0    0.0000
   Shor a=7 mod 15      5    4        4    1.5406
   Shor a=2 mod 15      5    4        4    1.5406
   Shor a=2 mod 21      6    5      156    5.2286
   → Simon: 선형이라 T_proxy=0·M₂=0 인데도 지수 *쿼리* 우위(magic 불필요).
     Shor: modexp 비선형이라 오라클이 T 비용·magic 둘 다 강제. 같은 비선형성이 원천.

## 결론 — 과제 C+D 통합
   • 상태 magic M₂(|ψ_f⟩) 과 오라클 게이트분해의 비클리포드(T) 비용은 *같은 비선형성*에서
     나오며 둘 다 f 아핀에서만 0 (따름정리 1 + ANF 차수≥2 ⟺ Toffoli/T).
   • '쿼리 오라클이 magic을 숨긴다'(T3b) = 'T 비용을 블랙박스로 숨긴다'와 동치 — Simon(0)
     vs Shor(>0)로 정량화. (2507.16543의 Clifford-가림과는 다른 메커니즘: 오라클 추상화.)
