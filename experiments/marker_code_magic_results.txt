# 측정: magic.sre2 (XOR-FWHT). 정정 객체: 자기상관 A_W / Walsh 4차 모멘트.

## 0. 정확 항등식 검증  sre2(flat_W) == autocorr/Walsh 공식  (보정 객체가 정확함)
   max|sre2 − autocorr공식| = 4.00e-15  (32 random W) → 자기상관/Walsh가 정확 객체

## 2b. τ ↔ M2 상관 (근사 예측식의 후보) 및 τ=0 ⟺ M2=0 무결성
   샘플 124개 (아핀 4 + 랜덤 비아핀).  Pearson r(τ, M2) = 0.764
   비영점 추세  M2 ≈ 7.743·τ^0.319  (근사; 통계적 예측식의 1차 후보)
   τ=0 ⟺ M2=0 위반 건수 = 0  (0이어야 정상: 정정 판정 무결)
   → τ는 정확한 영점 판정이자 magnitude의 단조 근사 지표. 정확값은 §0 Walsh 4차 모멘트.

## 결론
   · 보정 객체 = 자기상관 A_W / Walsh 4차 모멘트 (최소 해밍 거리 아님; §0,§1).
